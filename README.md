# Fun Festival Music 2024

Welcome to the official repository for the **Fun Festival Music** website. This is a full-stack web application built to provide a modern, interactive experience for festival attendees.

![Festival Preview](MusicFestivalWeb.png)

## Features
* **Dynamic Landing Page:** Clean design with a custom registration modal.
* **Interactive Stages:** A dedicated stages page featuring an integrated music player that updates track names and album art in real-time.
* **FAQ & Contact:** Fully styled information and contact sections with instant user feedback.
* **Responsive Design:** Optimized for a professional look across different screen sizes.

## Tech Stack
* **Backend:** Python (Flask)
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** SQLite (SQLAlchemy)
* **Icons:** [Ionicons](https://ionicons.com/)
